# ADR-012: Documents are imported by PWR, with one decompressor as the only new dependency

**Status:** Accepted, 2026-09-06. **Decision:** PDF text extraction is written in this workspace against `flate2`; no PDF library is taken as a dependency, and no extraction is offered that cannot be checked.

A document in a workspace used to be read as though it were text. The campaign of 2026-09-06 measured the cost: the deployment received a header, an object graph and an ASCII85 image stream in place of a CV, and spent eight actions and both its compactions on that. Refusing the read is half the answer; the document was the task, so the other half has to exist.

Three ways to get it. A Python extractor is prohibited by the runtime rule. A PDF crate would arrive as a parser of untrusted input with a dependency tree behind it, in a project whose dependencies are named one by one and reviewed. Writing the extraction here takes `flate2` and nothing else — a stream decompressor, pure Rust, the narrowest thing that makes a PDF readable at all.

The cost of writing it is that it is narrower than a library, and the discipline is that the narrowness must be visible. It reads content streams, simple-font encodings and declared link annotations. It does not OCR a scan, resolve a CID font's glyph ids without a `ToUnicode` map, or preserve layout. Each of those is a named refusal rather than a degraded result, because text that reads like text and is not is the failure this exists to prevent: the first version of this extractor returned 40 KiB of ASCII85 as though it were a CV, and passed its own plausibility check while doing it, since ASCII85 is printable. Declared filters are read for that reason, and an image stream is skipped because it says it is one.

Checked against the campaign's own CV: identical to `pypdf`'s extraction of the same file, character for character once whitespace is normalised, and it additionally recovers the seven link targets that the text alone does not carry. One document is not a corpus, and this is the evidence there is.

The output is a file beside the source, not a tool result: a CV is several thousand tokens, the run that needed one survived two compactions, and a file can be re-read in windows, searched, and quoted against afterwards. Its header names the source and its hash, so a claim about the document can be checked against the document.
