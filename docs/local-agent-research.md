# Research thesis, prior art and falsifiable hypotheses

**Authoritative research direction, 2026-09-12.** This replaces the earlier research contract; historical experiments remain in [experiment-log.md](experiment-log.md) and `experiments/`. Proposed benefits below are HYPOTHESES. No new model evaluation was run for this revision.

## What the evidence supports

PWR should investigate **deployment-conditioned reduction of agent bookkeeping and execution error**, not an ever-larger feature set. It already contains substantive tools, probes, calibration and a verified action loop. Its strongest evidence is that harness defects can look like model weakness: incorrect message serialization, evidence discarded before use, and a repair completion contract applied to read-only diagnosis. Fixing those defects is necessary correctness work; it is not by itself a novel adaptive architecture.

The possible contribution is a small, measurable policy that chooses among established action/context representations using behavior observed from a local deployment, with persistent source-linked state and recovery based on actual effects. The test is whether it improves completion or cost over **the best fixed policy selected on development data**, including adaptation overhead, on unseen repositories. A generic loop alone is too weak a control to establish that adaptation is necessary.

The transferable pattern is a reliable environment and feedback loop: retrieve evidence, expose tractable actions, execute under policy, observe effects, preserve state and verify the result. Decorative chat panels are category A. Evidence selection, correct tool protocols and verification are B. Unsupervised summarization, open-ended decomposition, code-generated orchestration and critic consensus are C unless tested. D is the opportunity: the same deterministic step may save a weaker model multiple uncertain inference turns. The size of that effect remains unknown.

## Local-model limitations: what is known and what must be measured

[BFCL (ICML 2025)](https://proceedings.mlr.press/v267/patil25a.html) separates single-call behavior from multi-step/stateful tool use. PWR should distinguish parse validity, schema validity, correct tool choice, valid state-dependent arguments and successful environment effects. Grammar constraints can improve only part of that chain. A call that parses but edits the wrong file is still a failed action.

[Lost in the Middle](https://arxiv.org/abs/2307.03172) motivates testing evidence position; [RULER](https://arxiv.org/abs/2404.06654) motivates multi-needle, tracing and aggregation tests beyond one recalled string. Neither gives a universal useful context limit for today's local models. Sweep occupancy, distractors, ordering and dependency depth on actual deployments. Retention, retrieval and reasoning after retrieval need separate measurements.

[Quantization evaluation](https://arxiv.org/abs/2402.16775) finds heterogeneous quality/efficiency tradeoffs. Bit width or parameter count alone cannot rank an agent: quantizer, backend kernels, offloading, KV-cache format and task sensitivity all matter. Test quantizations of the same weight family at fixed harness settings; label cross-family comparisons as deployments rather than pure size/quantization effects. [Ollama's context guidance](https://docs.ollama.com/context-length) also makes loaded context and memory/offload conditions relevant. Declared capacity is not delivered capacity.

[Agentless](https://arxiv.org/abs/2407.01489) provides a serious alternative: constrained localization, repair and validation rather than unrestricted orchestration. Use a staged workflow as a baseline. [AI Agents That Matter](https://arxiv.org/abs/2407.01502) motivates cost-aware evaluation, holdouts and reproducibility; a more expensive search can raise success without making the harness more efficient.

These sources do not prove that all local models fail in the same way. The working explanation is an interaction: imperfect instruction/tool training plus protocol/template mismatches, small effective evidence budgets, noisy observations, repeated bookkeeping, and a finite local inference budget. Multi-step reliability can compound failures, but per-step errors are correlated; do not estimate long-task success by multiplying a single probe rate.

## Repository evidence and competing explanations

The [experiment log](experiment-log.md) and [calibration notes](calibration.md) contain useful development observations:

- Preserving a just-read result changed a single compaction task from 0/1 to 1/1, with fewer turns. This demonstrates a harness loss, not a general effect size.
- A read-only completion-contract correction changed 0/6 to 6/6 on a development diagnosis task. Lexical scoring and a residency change limit semantic and latency conclusions.
- A search-context experiment increased generated tokens by 31%. A later combined prompt/output treatment varied from −26% to +59% across deployments. Its attribution to “the instruction” is not isolated causality: use contemporaneous output × wording factorial controls.
- Deployment cost ordering reversed between diagnosis and repair. No universal “cheapest model” follows.
- Two local inference streams produced little aggregate speedup under the measured machine/backend conditions. This does not prohibit parallelism elsewhere; it makes serial execution the honest starting control.
- v5 repeated needle prompts can benefit from prefix caching. They cannot certify uncached repository reasoning at that context size.

The current [audit](adaptive-runtime/CURRENT_ARCHITECTURE_AUDIT.md) adds another confound: interactive chat does not use the same loop as measured scripted tasks. Separate that correctness/integration problem from claims about a smarter policy.

## Falsifiable hypotheses

The thresholds below are **proposed practical research gates, not measured gains or power calculations**. Freeze them with an independently piloted sample size before confirmatory runs. All efficiency hypotheses use a −3 percentage-point completion noninferiority margin; require the paired confidence bound to clear the margin, not merely a small observed difference. For uplift gates, require the point estimate to reach the stated minimum and the 95% paired interval to exclude zero. Zero observed new scope/policy/false-acceptance violations is an additional gate, not a proof of zero population risk. Underpowered/ambiguous outcomes are inconclusive. [Evaluation](evaluation.md) defines pairing and denominators.

| ID / rationale | Experiment and control | Primary measurement / success gate | If adequately powered evidence rejects the claim |
|---|---|---|---|
| **H1: capability-conditioned action representations reduce protocol burden.** Large catalogs and editing formats consume attention and invite malformed calls. | Same canonical tools and effects; universal schema versus bounded state-appropriate presentation. Include dependent calls, abstention and wrong-but-valid arguments. Freeze policy before holdout. | ≥30% relative reduction in unusable proposals, with a positive reduction interval and noninferior verified completion; report semantic tool-choice errors too. | Keep universal schema and explicit user profiles; retain deterministic correctness validation. |
| **H2: evidence-linked working state improves long tasks.** Conversation compaction loses requirements and stale evidence is reused. | Same context budget; pinned task + conversation baseline versus typed objective/claims/checks/evidence ledger. Inject requirement updates and external file edits. | ≥10 pp verified completion uplift on long-horizon set; ≥50% lower stale-evidence delivery as a secondary mechanism check. | Keep minimal durable task state; do not grow semantic memory. |
| **H3: structural retrieval saves context.** Shallow lexical names can miss relevant definitions and dependencies. | Existing lexical/shallow-symbol retrieval versus AST/LSP-backed symbols/edges; identical task/evidence access. Oracle-context diagnostic arm. | ≥20% reduction in all-attempt prompt tokens with noninferior completion; report indexing time/RAM and retrieval misses. | Keep lexical retrieval, exact search and optional language-specific lookup; no mandatory vector/AST service. |
| **H4: deterministic result views save inference.** Logs bury actionable evidence. | Bounded raw output versus parsed diagnostics + retrievable raw artifact, crossed with unchanged versus concise task instruction in a 2×2 design. | ≥20% lower all-attempt generated tokens with noninferior completion; no missing critical diagnostic fields in fixtures. | Keep bounded raw output; retain only individually justified parsers. |
| **H5: effect-specific recovery beats repeated prompting.** A known failure should not require another semantic diagnosis. | Current retries versus bounded failure-class transitions at equal total budget; inject stale hash, missing path, failed patch, large output, timeout and contradictory check results. | ≥15 pp recovery-to-verified-completion uplift; noninferior clean-task completion; false-stop rate reported. | Prefer simple stop/escalate policy; remove speculative strategy mutation. |
| **H6: measured adaptation beats a strong fixed policy.** A benefit from one representation does not prove a selector is useful. | Freeze candidate policies and fit their selector on development tasks/probes; compare with best global fixed policy and best fixed policy per deployment on repository-disjoint holdout. Include probe cost. | ≥15% all-attempt wall-time reduction with noninferior completion in each claimed supported cohort; positive paired reduction interval. | Use explicit/static configuration. No automatic adaptive-policy advantage is claimed. |
| **H7: scoped serial workers improve decomposition.** Context isolation may help even when one GPU cannot accelerate parallel streams. | Single agent versus serial workers at equal aggregate inference/operation budgets; independent subtask and integration verifiers. Parallel arm is a later separate latency experiment. | ≥10 pp completion uplift on multi-component tasks after counting integration failures and all worker calls. | Keep one agent; allow only safe independent tool concurrency. |

H1–H5 are interventions; **H6 tests the primary adaptive thesis**. Improvements from correctness repairs or more compute alone do not satisfy H6. H7 is explicitly outside the minimum core until single-agent evidence warrants it. Probe variants for H6 must predict a useful policy decision on held-out tasks; predicting needle recall is insufficient.

## Open questions and decision boundaries

1. Does cheap calibration predict policy choice better than early-session observations? Measure predictive utility and break-even task count including warmups and invalidations.
2. Which evidence needs verbatim retention versus a structured fact or rehydration pointer? Test source deletion, branch changes, compaction and contradictory claims, not recall alone.
3. When does deterministic structure overconstrain a model that would solve the task directly? Include the simple staged and full-catalog baselines; retain a visible escape/discovery path.
4. Does external planning help only at particular dependency depths? Compare no plan, model plan and deterministic dependency state separately; no universal plan-first default.
5. Can procedures derived from successful traces generalize without preserving a task-specific shortcut or unsafe instruction? Require new-task replay and provenance before memory promotion.
6. How should CPU, RAM/VRAM, prefill, decode and cache costs affect scheduling? Measure complete deployment loading and integration costs before multiple local models become architecture.
7. Which screenshot/UI defects require vision rather than DOM, accessibility or ordinary tests? Later capability-gated experiments must separate these information sources.
8. How much apparent local-model weakness remains with oracle evidence and a correct protocol? This can bound preventable failures, but does not prove what a deployable context policy can achieve.

A publishable outcome can be a negative result: a fixed policy may be as good as calibration-driven adaptation. In that case the useful contribution is the failure taxonomy, controlled dataset, measured limits and simpler reliable harness—not a rebranding of unchanged results as intelligence.
