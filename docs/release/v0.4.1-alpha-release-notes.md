# PWR v0.4.1-alpha

Maintenance release for Apple-silicon Macs, following v0.4.0-alpha.

## Fixes

- Local web preview uses an isolated native webview, so development sites with `X-Frame-Options: SAMEORIGIN` or `frame-ancestors` can be displayed without changing their security headers. Navigation remains limited to local HTTP/HTTPS development servers; the preview has no PWR IPC capabilities. Closing the panel or reloading the desktop interface removes the native view.
- Terminal supports independent shell tabs. Switching tabs preserves their buffers and running commands. Colours are resolved in the current application theme before being passed to xterm, fixing unreadable output in the light theme.
- Historical turns whose entries share a completion timestamp display elapsed time **since request**, rather than an incorrect zero-second generation duration. This value includes queue time and is labelled accordingly; live turn timing remains distinct.

## Verification

Release checks and the native IssueDock session are recorded in `docs/release/v0.4.1-alpha-verification.md`. Screenshot source sessions include an actual Gemma 4 31B task and real local application output; screenshots from development are labelled as such.

## Limits

This is still an alpha. The macOS application is ad-hoc signed and **not notarized**. Gemma assistants remain experimental and off by default; this release makes no new model-quality, speed or memory-tier claims. No model weights, templates or training data were changed.

Download `PWR-macOS-arm64.dmg` and `SHA256SUMS.txt` together and run `shasum -a 256 -c SHA256SUMS.txt`. Keep the previous version to roll back if necessary; do not disable Gatekeeper globally.
