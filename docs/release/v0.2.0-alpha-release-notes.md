# PWR v0.2.0-alpha

Mac alpha for Apple silicon.

## What changed since v0.1.2-alpha

- **Focus is the desktop layout.** The six-layout experiment has ended. Focus
  keeps the conversation central, with a compact composer and resizable cards
  for files, project knowledge, terminal and local preview. The UI also groups
  a run into phases, allows queued messages to be edited, and supports rewind
  of conversation state. A run can be read Compact, Detailed or as a Raw
  Trace with every event and the core log. The macOS full-screen title bar
  draws over the app.
  Rewind does not undo arbitrary command effects.
- **Faster follow-up turns.** The MLX prompt cache persists across messages;
  background wiki summaries use their own cache instead of evicting the
  conversation's. Speed still depends on the model, prompt and Mac.
- **More projects can run their own checks.** PWR can install missing
  toolchains inside a workspace and use them for both agent commands and
  verification. Sandbox handling has been extended for Swift, JVM tools and
  .NET. Network, Docker and commands outside the workspace's allowed list
  ask for permission in Ask mode.
- **Goal mode checks more carefully.** A failing declared acceptance check
  prevents a verified completion. After checks pass, a review round compares
  the work with the request; a second reader may identify requirements the
  code missed. These checks reduce false completion claims but do not
  guarantee a correct solution.
- **Agent and model handling improved.** Tool-call recovery, command timeout
  output, offline-install guidance, Model Manager catalogue and sizing, and
  project recall were refined. The model profile exposes MLX sampling settings
  and user overrides. `look_at` can show a local page to a model that supports
  image input; this path remains experimental.

## Evidence and limits

Two development campaigns on 31 tasks recorded 19 and 22 independently
verified completions, one run per task. They do not compare this version with
v0.1.2-alpha and do not establish a general success rate. The later **reduced
c4 run** recorded **7 passes in 9 tasks**, including **5 in 6 held-out tasks**
that were not used to tune PWR. Its other two tasks failed. This was one run
per task on the pinned `d313acd9` binary; it does not score the whole 37-task
corpus or validate the later Focus UI. See
[`evidence/stack-matrix/README.md`](../../evidence/stack-matrix/README.md)
for the task and verification protocol.

PWR remains an alpha for Apple-silicon Macs. It is ad-hoc signed and not
notarized. Vision input and `look_at` are experimental; Windows, a persistent
GGUF desktop path, and a unified scripted/conversation runtime remain outside
this release.

## Install

After publication, download `PWR-macOS-arm64.dmg` and `SHA256SUMS.txt` from
this release. In their directory run `shasum -a 256 -c SHA256SUMS.txt`, then
open the DMG and drag PWR to Applications. On first launch macOS may block the
ad-hoc signed app. If you trust the downloaded copy, use **System Settings →
Privacy & Security → Open Anyway** after attempting to open it. Do not disable
Gatekeeper globally.

On first launch PWR installs its private MLX engine. Download a model from the
Model Manager, then open and trust a workspace. Read
[`SECURITY.md`](../../SECURITY.md) before using an agent on important files.
