# PWR v0.1.2-alpha

Maintenance prerelease for macOS on Apple silicon (arm64).

## Changes

- Let `pwr run` be repeated in the same workspace. The computed execution profile is content-addressed and written once, but one of its fields was random, so the second run refused to overwrite the first run's profile with a `conflict` error.
- Find the MLX engine installed by the desktop app when `pwr` is started from a shell without `PWR_MLX_PYTHON`. Previously the core fell back to the system `python3`, which has no MLX, and every capability probe came back `unknown`.

Both issues were found while PWR itself polished the PWR website from the command line.

## Install and verify

Download [PWR-macOS-arm64.dmg](https://github.com/VitoSanta/PWR/releases/download/v0.1.2-alpha/PWR-macOS-arm64.dmg) and [SHA256SUMS.txt](https://github.com/VitoSanta/PWR/releases/download/v0.1.2-alpha/SHA256SUMS.txt). Put both in the same directory and run:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

The output should report `PWR-macOS-arm64.dmg: OK`. Open the DMG and drag PWR to Applications. The app is ad-hoc signed, not notarized by Apple. If macOS blocks the first launch, verify the checksum, then use **System Settings → Privacy & Security → Open Anyway** for PWR. Do not disable Gatekeeper globally.

PWR's first-run setup installs its private MLX engine; a local model must then be downloaded in Model Manager.

## Current limitations

- This desktop release supports macOS on Apple silicon.
- No model currently has PWR's Verified status.
- A local model can still return malformed tool calls or struggle with a long task. Inspect changes and repository checks before relying on its result.

Report reproducible failures in [GitHub Issues](https://github.com/VitoSanta/PWR/issues).
