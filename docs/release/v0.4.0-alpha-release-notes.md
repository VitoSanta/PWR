# PWR v0.4.0-alpha

Mac alpha for Apple silicon.

## What changed since v0.3.0-alpha

- **PWR runs Gemma 4, and only Gemma 4.** Support for other model families,
  and for Ollama and LM Studio, is removed. One family means one chat
  template and one tool-call format, rendered as Google describes them (the
  template of 2026-07-09, the empty thought block after a tool result, tool
  results as mappings, images with attention both ways inside an image). The
  model registry, the profiles and the catalogue hold the Gemma 4 packs only.
- **One pack per memory tier.** Gemma 4 E2B, E4B and E4B QAT for 16 GB Macs
  (131,072-token context); 12B, 26B-A4B (4-bit, QAT 4-bit, 6-bit) for 24 GB
  and up; 31B 8-bit for 64 GB and up, each of these with a 262,144-token
  context where the Mac's memory holds it. The Model Manager says how much of
  that context this machine holds for each pack. Thinking is a switch, off
  unless turned on.
- **Assistants, as an experiment.** Each pack has a small assistant model for
  speculative decoding. The Model Manager downloads it from its own registry
  entry (pinned revision, every file checked) and a switch in the model's
  panel turns drafting on. It is off by default: no pack has passed the
  exact-text and 1.4× speed gates, and penalties or an 8-bit cache fall back
  to normal decoding.
- **Long context.** The engine can hold a long context once and bound a
  prefill step; the context cache stays at 16 bits unless a window needs 8
  (engine switches, off unless asked for). A 6 GiB reserve is kept on every
  tier.
- **A redesigned desktop app.** Google's Material 3 as the foundation, Google
  Sans, light and dark themes. No top bar: the conversation fills the window
  and every control sits in the message bar, which grows with the text, glows
  while PWR works and, at rest, folds into the PWR mark. Answers have no
  header; the new PWR mark turns while Gemma works. A right click (a
  two-finger click) on an empty spot opens the tools as a wheel; the bar's
  Options hold the trace detail, Goal & approvals, commands and settings.
  Tool cards slide in and out beside the chat. New app icon.
- **Goal mode.** Turn recovery is bounded and an exhausted goal stops. Empty
  search outcomes count toward bounded progress recovery; failing reproducer
  assertions are kept apart from implementation defects; the review evidence
  includes changed tests. Optional goal aids (off unless asked for) run the
  tests related to a changed file before and after, and tell a test call that
  ran none what it was.
- **Engine.** MLX 0.32.3, mlx-lm 0.32.0, mlx-vlm 0.7.8, on Python 3.14. An
  engine installed by an earlier version is offered for reinstallation.

## Evidence and limits

Checked on the candidate commit (`2022949f`) on the maintainer's Mac:
formatting and Clippy clean; the full Rust suite, 1,556 passed, 6 ignored and
one failed in 109 binaries. The failure was
`site::tests::a_route_with_no_file_is_answered_with_the_index_and_nothing_above_the_site_is`
(`pwr-tools`), a connection reset by its local test server under parallel
load; it passed alone five times out of five, in three further runs of the
crate, and in the previous full run. It is intermittent, not counted as a pass.
The sidecar's 92 tests (1 skipped), the public-documentation check, a clean
`npm ci`, the 107 desktop tests and the production build passed.
`scripts/release-macos.sh` built and verified `PWR-macOS-arm64.dmg` (SHA-256
`36fae659f718e0855597fc3dabaf1238a056710f3fa740cf4e333e66b163168a`, a local
build; the published artifact is built by the tag workflow and has its own
checksum). The manual native-app list was not run for this candidate.

Recorded during development (2026-10-14, benchmark `prove-app-20261014-r2`):
a native goal with Gemma 4 in the desktop app, verified, two tests green, in
100 seconds with the sandbox active. One run; it establishes no success rate.
Benchmarks of the Gemma line also show concrete failures: incorrect tool
calls, misread test outcomes and tasks that do not reach a conclusion.

PWR remains an alpha for Apple-silicon Macs. It is ad-hoc signed and not
notarized. Assistants, page steps and vision input are experimental. Windows
remains outside this release.

## Install

After publication, download `PWR-macOS-arm64.dmg` and `SHA256SUMS.txt` from
this release. In their directory run `shasum -a 256 -c SHA256SUMS.txt`, then
open the DMG and drag PWR to Applications. On first launch macOS may block the
ad-hoc signed app. If you trust the downloaded copy, use **System Settings →
Privacy & Security → Open Anyway** after attempting to open it. Do not disable
Gatekeeper globally.

On first launch PWR installs its private MLX engine; an engine installed by an
earlier version is offered for reinstallation. Download a Gemma 4 pack from the
Model Manager, then open and trust a workspace. Read
[`SECURITY.md`](../../SECURITY.md) before using an agent on important files.
