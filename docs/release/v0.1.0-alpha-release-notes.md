# PWR v0.1.0-alpha

First public alpha of PWR.

## Platform

- macOS
- Apple silicon (arm64)

## Status

Alpha software. Behavior, APIs and packaging may change.

## Highlights

- A Tauri desktop app backed by PWR's Rust core and local MLX inference engine.
- A streamed coding-agent conversation with typed tools, workspace permissions,
  approval prompts and inspectable file diffs.
- Model discovery and memory fit estimates, verified model downloads, and a
  first-run setup for the local inference engine.
- Chat without a workspace, with only attached material available to the model.

See the [README](https://github.com/VitoSanta/PWR/blob/main/README.md) and
[product source of truth](https://github.com/VitoSanta/PWR/blob/main/docs/PWR_PRODUCT_SOURCE_OF_TRUTH.md)
for scope and documented limitations.

## Installation

Download [PWR-macOS-arm64.dmg](https://github.com/VitoSanta/PWR/releases/download/v0.1.0-alpha/PWR-macOS-arm64.dmg)
and [SHA256SUMS.txt](https://github.com/VitoSanta/PWR/releases/download/v0.1.0-alpha/SHA256SUMS.txt).
Open the DMG and drag PWR to Applications. On first launch, PWR offers to
install its private MLX engine; this downloads about 1.2 GB. Then use Model
Manager to download a model.

## macOS security notice

This build is ad-hoc signed and is not signed with a Developer ID certificate
or notarized by Apple. macOS may block the first launch because it cannot
verify the developer or check whether the app was modified. Only continue if
you trust the downloaded artifact and have checked its checksum. After trying
to open PWR, use **System Settings → Privacy & Security → Open Anyway**, then
confirm. See [Apple's instructions](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac).
Do not disable Gatekeeper globally or remove quarantine attributes.

## Integrity

`SHA256SUMS.txt` is generated from the final DMG with macOS `shasum -a 256`.
To verify the download in Terminal, put the checksum file beside the DMG and
run:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

The output should report `PWR-macOS-arm64.dmg: OK`.

## Known limitations

- This release supports macOS on Apple silicon. The workspace sandbox is
  macOS-only.
- No model currently has PWR's Verified status.
- Context composition is estimated at four characters per token.
- The desktop conversation and scripted runner still differ in planning,
  compaction and recovery.
