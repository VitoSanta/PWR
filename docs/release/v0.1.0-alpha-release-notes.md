# PWR 0.1.0 — public alpha

The first public release of PWR: a local coding agent for Apple-silicon Macs.
It runs open-weight models on its own MLX engine and works inside a folder you
choose, through sandboxed tools. It checks its work with the repository's own
build and test commands.

PWR is open source (Apache-2.0) and changes quickly. This build is usable
today; expect rough edges, and read [SECURITY.md](../../SECURITY.md) before
pointing it at anything you care about.

## Download

`PWR_0.1.0_aarch64.dmg`, for macOS on Apple silicon (M1 or later).

1. Open the DMG and drag **PWR** to **Applications**.
2. Open PWR. This alpha is not yet notarized by Apple, so macOS stops it the
   first time. Close the dialog.
3. Go to **System Settings → Privacy & Security**, find the message about
   PWR, click **Open Anyway** and confirm. Later launches open normally.
4. On first launch PWR installs its engine: a private Python with pinned MLX
   packages, about 1.2 GB. Then open the **Model Manager** from the model chip
   and download a model. It goes to `~/.pwr/models`.

## What is in it

- **Agent conversation.** Streaming replies and reasoning, actions shown as
  they run, steering mid-turn, stop, and **Goal mode**, which keeps working
  until your declared acceptance check passes.
- **Tools.** Read, search (including installed dependencies), find
  definitions, hash-guarded edits, file operations, commands without a shell,
  local services, Git status and diff. Everything runs under macOS's sandbox,
  confined to the workspace.
- **Permissions.** Ask mode is the default. It asks before dependency changes,
  network access, toolchain installs, Git history rewrites and publishing.
  Auto mode grants those without asking.
- **Verification.** PWR discovers your repository's checks from
  `.pwr/checks.json`, CI configuration, `package.json` or 19 build systems. It
  runs them before and after edits and reports what they said.
- **Changes and evidence.** Per-file diffs with Revert, which goes through the
  core and never overwrites a later manual edit. The Evidence panel has
  Verify, Report, Diagnose and Doctor. Every action is recorded in a local,
  hash-chained log.
- **Models.** The Model Manager searches Hugging Face for MLX models, rates
  each one for your Mac's memory, and downloads it with checksum
  verification and resume. Unknown models run as *Provisional*. A
  nine-request Quick Calibration marks them *Locally calibrated* or *Limited*.
  Reasoning Effort (Low / Medium / High) bounds thinking in the engine.
- **Context.** The window is computed from your memory and the model's
  configuration. There is a context panel, plus automatic and manual
  compaction without a model-written summary.
- **Chat mode** without a workspace; attached files, folders and images (for
  models with a vision encoder).

## Privacy

Inference, tools, verification and logs stay on your Mac. PWR uses the
network to install its engine once, to search and download models from
Hugging Face when you ask, and for agent actions only when you grant network
access. There is no telemetry and no account.

## Known limits

- macOS on Apple silicon only. Windows is planned; Linux is not a target.
- Not notarized; ad-hoc signed.
- No model carries PWR's *Verified* status yet. Quick Calibration shows that
  PWR can operate a model, not that the model is good at the work.
- Context composition is an estimate (four characters per token). The
  engine's own token count is exact.
- Documentation and other prose tasks cannot be verified mechanically, and
  PWR says so.
- The conversation and the command-line runner (`pwr run`) still differ in
  planning, compaction and recovery.
- The llama.cpp/GGUF engine is experimental and command-line only.
- No measured claim is made about how much PWR improves a model; that study
  is next.
